🚀 **INTRODUCING SOC NEXUS — FROM A CYBERSECURITY LAB TO A UNIFIED SOC COMMAND CENTER.**

A SOC is more than a collection of security tools. It's how monitoring, intelligence, investigation, and automation work together.

That's the idea behind **SOC NEXUS**, my self-developed Security Operations & Automation Center.

Built through months of learning, experimentation, integration, troubleshooting, and continuous improvement, this project brings multiple security technologies into one analyst-focused environment.

🔥 **WHAT'S INSIDE SOC NEXUS?**

🔎 **Splunk Enterprise** — Security event monitoring, detection visibility, analytics, and incident exploration.

⚙️ **n8n** — Workflow automation and execution monitoring.

🧠 **MISP** — Threat intelligence and indicator enrichment workflows.

🚨 **TheHive** — Incident and case-management within the wider response architecture.

🛡️ **Investigation Workspace** — Incident exploration, evidence visibility, and investigation workflows.

🔐 **Secure Gateway** — Dedicated analyst authentication, password hashing, CSRF protection, secure sessions, and HTTPS.

🔊 **Audio Command Center** — Custom sound profiles, alert controls, quiet hours, and event history.

🎨 **NEXUS ONE / ORBIT** — A custom futuristic interface combining service health, detection analytics, incident management, and automation visibility.

**THE ENGINEERING BEHIND THE PROJECT**

My goal wasn't simply to create an attractive dashboard. It was to understand how different security technologies communicate, how workflows connect, and how to create a structured environment that supports real SOC learning and operations.

I also focused on secure access, read-only routine monitoring, preserving existing integrations, and keeping sensitive response actions under analyst control.
