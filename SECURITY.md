# SOC NEXUS - Security Policy

## Repository Security
This repository is a public-facing project showcase.

## Sensitive Information
Never publish:
- Passwords or API keys.
- Authentication tokens or session cookies.
- Private keys or certificates.
- CSRF tokens and authentication headers.
- Database files and private backups.
- Sensitive internal configuration.
- Personal information not intended for public release.

## Screenshot Review
Review all screenshots at full resolution before publication.
Check login screens, integration settings, URLs, usernames, and operational records.
Redact sensitive information from publication copies.
Keep the original captures unchanged.

## Credentials
Keep credentials outside the public repository.
Use environment variables or an approved secrets manager.
Never commit live service credentials.

## Project Scope
This repository is currently a documentation and visual showcase.
It is not an installable application or an independently audited security release.

## Reporting
Do not disclose sensitive vulnerabilities or credentials in public issues.
